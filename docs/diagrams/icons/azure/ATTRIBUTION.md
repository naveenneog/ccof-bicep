# Microsoft Azure architecture icons

These unmodified SVGs are selected from Microsoft's **Azure Public Service Icons V24**:

- [Official icon guidance and permitted use](https://learn.microsoft.com/azure/architecture/icons/)
- [Microsoft-hosted V24 collection](https://arch-center.azureedge.net/icons/Azure_Public_Service_Icons_V24.zip)

Microsoft permits these icons in architecture diagrams, training materials and
documentation, and reserves other rights. Their inclusion here is for the diagrams
and documentation in this repository; it does not add a general license to this
repository or imply Microsoft endorsement.

`manifest.json` records each collection entry and the SHA-256 of its original SVG.
Do not redraw, crop or recolor the service logos. The diagram generator scales them
with their aspect ratio preserved, and embeds them in the editable draw.io and SVG
previews so neither requires remote icon retrieval.
