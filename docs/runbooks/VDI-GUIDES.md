# CCOF guides for a Windows VDI

These text-only guides use placeholders in place of deployment-specific values.

| Guide | Purpose |
| --- | --- |
| [Deployment, DR and email alerts](VDI-DEPLOYMENT.md) | Operator prerequisites, staged deployment, standby and monitoring |
| [Developer onboarding](VDI-DEVELOPER.md) | Azure CLI sign-in, Claude Code and VS Code |
| [Admin console](VDI-ADMIN-CONSOLE.md) | Console access, projects, members, models and client downloads |
| [Claude Desktop](VDI-DESKTOP.md) | A single-device gateway pilot and verification |

Values beginning with `REPLACE-` come from the platform or identity team. Configuration
files and deployment state can contain internal identifiers; keep them in approved private
storage, outside the repository. Access tokens, passwords, client secrets, prompt text and
raw request bodies do not belong in tickets, screenshots or public pull requests.

The [deployment runbook](DEPLOY-STEP-BY-STEP.md), [client reference](../CLIENTS.md)
and [admin operations guide](ADMIN-OPERATIONS.md) are the detailed references.
